# Roadmap

## v0.1 — shipped alpha

- Behavior Card v1 schema, validation and content hashes.
- Python AST matcher, optional pinned TypeScript/TSX tree-sitter adapter, deterministic
  JavaScript structural tokens, and a Git diff parser.
- CLI, read-only GitHub Action, MCP server, Agent Skill, SARIF/HTML and static demo.
- One evidence-complete Astropy vertical slice and bounded SWE-bench snapshot pipeline.

## v0.2

- Dedicated JavaScript tree-sitter adapter and deeper TypeScript symbol/call-edge extraction.
- GitHub Compare/PR API ingestion with fork/cherry-pick/revert patch-id deduplication.
- 30 full upstream behavioral capsules validated in isolated Actions.
- Richer line annotations, an opt-in SARIF upload recipe, and a broader negative-control corpus.

## v0.3

- Incremental SQLite evidence graph, CodeQL interoperability, signed capsule attestations.
- Cross-repository research benchmark with confidence intervals and agent A/B runs.
