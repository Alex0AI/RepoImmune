# Resume-ready project description

## English

**RepoImmune — Evidence-backed regression memory for AI coding agents**  
Designed and shipped an Apache-2.0 developer tool that mines resolved GitHub bugs into versioned Behavior Cards linking issues, buggy/fixed commits, AST patterns, regression tests, symbols, licenses and replay capsules. Built a dependency-free Python CLI, read-only GitHub Action, SARIF/HTML reporting, six-tool MCP server and static demo; added deterministic mutation/retrieval experiments and explicit verified/external/heuristic/inconclusive evidence classes.

## 中文

**RepoImmune —— 面向 AI Coding Agent 的证据化防回归记忆**  
从零设计并发布 Apache-2.0 开发者工具，把 GitHub 已修复 Bug 转换为带版本的 Behavior Card，连接 Issue、Buggy/Fix Commit、AST 模式、回归测试、符号、许可证与可回放 Capsule。完成零运行时依赖 Python CLI、只读 GitHub Action、SARIF/HTML 报告、六工具 MCP Server 和静态 Demo，并建立确定性 mutation/检索实验与 verified、externally reported、heuristic、inconclusive 四级证据体系。
