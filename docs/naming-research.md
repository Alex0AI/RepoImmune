# Naming research

Checked 2026-08-20 against GitHub repository search, exact npm registry endpoints, exact PyPI JSON endpoints and web search.

| Candidate | Result |
|---|---|
| BugMemory | Rejected: an active, directly adjacent debugging-memory product was publicly launched under this name. |
| SpecRecall | Exact npm/PyPI/GitHub repository collision not found, but the name reads as requirements recall rather than regression immunity. |
| RegressionAtlas | Exact registry collision not found; longer and sounds primarily observational. |
| RepoImmune | Exact `repoimmune` and `repo-immune` npm/PyPI names returned 404; GitHub repository search returned no exact repository; web search found no obvious adjacent product. Selected for shortness, memorability and direct product metaphor. |

This is a practical collision search, not a trademark opinion or guarantee. Contributors should repeat it before a major commercial launch.
